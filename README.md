# Photo Booth Hire Swansea

Marketing site for Photo Booth Hire Swansea — wedding, prom, corporate and party
photo booth hire across Swansea, Cardiff, and South Wales.

## Domains

- Primary domain: `photoboothhireswansea.co.uk`
- Cardiff domain: `photoboothhirecardiff.co.uk` (redirects to `/photo-booth-hire-cardiff`)
- Email: `photoboothhireinwales@gmail.com`

## Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- TypeScript
- Resend (email) and Stripe (invoicing) via API route handlers

## Pages (`app/`)

- `/` — Home (`app/page.tsx`)
- `/about` — About Us
- `/photobooths` — Selfie Pod, Magic Mirror, Enclosed Booth overview
- `/packages` — Pricing for all three booths
- `/events` — Events we cover
- `/services` — Wedding, prom, corporate, birthday hire
- `/testimonials` — Client reviews
- `/faq` — Frequently asked questions
- `/contact` — Contact form
- `/gallery` — Event gallery
- `/backdrop` — Backdrop options
- `/booking` — Booking form (creates Stripe invoice)
- `/quickquote` — Quick quote form
- `/pay` — Stripe payment landing (noindex)
- `/how-it-works` — Booking flow walkthrough
- `/photo-booth-hire-cardiff` — Cardiff local SEO landing page

## Environment variables

Required for the booking and payment flows to work end-to-end:

- `RESEND_API_KEY` — Resend API key
- `RESEND_FROM_EMAIL` — Verified sender address
- `RESEND_TO_EMAIL` — Admin recipient address (e.g. `photoboothhireinwales@gmail.com`)
- `STRIPE_SECRET_KEY` — Stripe secret key
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` — Stripe publishable key (client)
- `NEXT_PUBLIC_STRIPE_BUY_BUTTON_ID` — Stripe Buy Button ID for the `/pay` page
- `NEXT_PUBLIC_SITE_URL` — Public origin used for canonical URLs and OG tags

Optional:

- `STRIPE_INVOICE_CURRENCY` — defaults to `gbp`
- `INVOICE_DAYS_UNTIL_DUE` — defaults to `7`

### Required environment variables in Vercel

Go to **Vercel Dashboard → Project Settings → Environment Variables** and add:

| Variable             | Value                                            |
| -------------------- | ------------------------------------------------ |
| `RESEND_API_KEY`     | (from resend.com dashboard)                      |
| `RESEND_FROM_EMAIL`  | `hello@photoboothhireswansea.co.uk`              |
| `RESEND_TO_EMAIL`    | `photoboothhireinwales@gmail.com`                |

These three values power the Quick Quote, Booking, and Contact email flows
(client confirmation + admin notification for each).

## Email system

Transactional emails are sent via [Resend](https://resend.com) using
[React Email](https://react.email) templates. All template files live in
`emails/` and share a single layout (`emails/components/EmailLayout.tsx`).

| Trigger                | Client email             | Admin email           |
| ---------------------- | ------------------------ | --------------------- |
| `POST /api/quote`      | `QuoteConfirmation`      | `AdminQuoteAlert`     |
| `POST /api/booking`    | `BookingConfirmation`    | `AdminBookingAlert`   |
| `POST /api/contact`    | `ContactConfirmation`    | `AdminContactAlert`   |

Booking emails include a unique invoice number generated by
`lib/invoice.ts` in the format `INV-PBH-YYYYMMDD-XXX`. The daily counter is
persisted in `data/invoice-counter.json` and resets at the start of each day.
